This plugin enables three search boxes and allows customers to search TIPs verse data directly within your website, helping them access specific inspirational verses seamlessly.

== Description ==

**TIPs: Find Verse Widget** provides a flexible and user-friendly interface to help your visitors discover inspirational verses using up to three different search filters: keyword, author/source, and topic.
 de-powered widget on your site, allowing customers to find and view specific TIPs content without ever leaving the page.

== Features ==

* Three powerful search boxes (keyword, author, topic)
* Seamless display of TIPs content
* Easily embeddable via shortcode: `[tips_find_verse]`
* Lightweight and easy to customize
* Styled out of the box (but developer-friendly)

== Installation ==

1. Upload the `tips-find-verse-widget` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin via the WordPress admin.
3. Use the shortcode `[tips_find_verse]` in any post, page, or widget.
4. (Optional) Customize styling or verse data source inside the plugin code.
